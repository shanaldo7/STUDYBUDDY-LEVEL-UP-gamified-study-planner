# Third-party UI inspirations

StudyBuddy's UI enhancement layer adapts dashboard design patterns from the following MIT-licensed projects:

1. Kstheme/Study-Planner — MIT License
   https://github.com/Kstheme/Study-Planner
   Used as inspiration for visual hierarchy, information cards, workflow steps, and analytics presentation.

2. imDarshanGK/AI-Study-Planner — MIT License
   https://github.com/imDarshanGK/AI-Study-Planner
   Used as inspiration for priority/risk-oriented study dashboard presentation.

The StudyBuddy implementation is customized for the existing Solo-Leveling/anime visual system and does not replace StudyBuddy's original UI/assets.
